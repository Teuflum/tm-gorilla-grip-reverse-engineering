# Gorilla Grip Rater

Install this folder as `OpenplanetNext/Plugins/GorillaGripRater`. Openplanet's VehicleState plugin is required. Enable or hide the HUD from Openplanet's menu and adjust its position, scale, minimum icing, minimum speed, minimum airtime, and force grade thresholds in plugin settings.

The HUD displays the normalized **internal steering** used for the strict `-0.1` / `+0.1` direction decision. The center band on the steering meter is that neutral zone. `LEFT` and `RIGHT` show the stored ice-slide direction, which can remain set while steering briefly returns to center. The force number is the physics tire-force multiplier, not a speed multiplier.

On the tested Trackmania build, the plugin obtains the current physics-car pointer from the active `CSmPlayer` at offset `0x1118`. It reads smoothed steering at `vehicle+0x1430`, direction mode at `+0x14e5`, and tire-force multiplier at `+0x14dc`. The read is enabled only when the executable's PE timestamp is `0x6980d607` and image size is `0x2cba000`, and when the car pointer passes wheel-count, model-pointer, position, raw-input, and field-range checks. It never writes game memory. If these checks fail, the HUD explicitly says **ESTIMATE**; `~` marks a provisional grade based on input simulation.

The rater watches flights with average tire icing at or above the configured minimum, enough takeoff speed, and enough airtime. It captures the stored direction at the first all-air display sample. It checks landing steering against the ±10% gate and grades the force about 30 ms after visible contact, once the grounded physics update has run. Matching direction with recovered force earns GOOD, GREAT, or PERFECT and builds a combo. Wrong direction, low force, or no steering direction breaks the combo. Full rotations during a PERFECT flight add a score bonus. The summary line shows the previous run's points and hits/misses.

**Rating scope:** The HUD measures the game fields above, but it does not directly measure longitudinal acceleration. A `PERFECT` grade means the stored direction matches landing steer and the checked tire-force multiplier meets the configured threshold. Actual speed changes still depend on the vehicle trajectory and other forces. Contact is observed once per display frame, so the exact last-wheel departure tick is not known from the HUD alone. The first settled force sample is normally 30–40 ms after first visible contact, depending on display timing.

Controlled TICK replay validation on this build used `right_13_from_1126_through_1131` and `right_12_from_1126_through_1131`. At the 12.58 s landing, the +13 run showed stored right mode and `2.00x` force just after contact; the rater gave PERFECT and speed at x≈782 was 230.944 km/h. The +12 run kept left mode before takeoff, switched right at contact, dropped to `1.00x`, and the rater gave WRONG WAY; speed at x≈782 was 227.332 km/h. Both readings were marked exact in the Openplanet log.
