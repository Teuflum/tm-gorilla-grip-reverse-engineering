# Gorilla Grip Rater

Install this folder as `OpenplanetNext/Plugins/GorillaGripRater`. Openplanet's VehicleState plugin is required. Enable or hide the HUD from Openplanet's menu and adjust its position, scale, minimum icing, minimum speed, minimum airtime, and force grade thresholds in plugin settings.

The HUD displays the normalized **internal steering** used for the strict `-0.1` / `+0.1` direction decision. The center band on the steering meter is that neutral zone. `LEFT` and `RIGHT` show the stored ice-slide direction, which can remain set while steering briefly returns to center. The force number is the physics tire-force multiplier, not a speed multiplier. While airborne it says **FORCE ON CONTACT** because there is no wheel force to rate yet: the stored multiplier can remain `1.00x` throughout a successful flight and update to `2.00x` on the first grounded force calculations.

On the tested Trackmania build, the plugin obtains the current physics-car pointer from the active `CSmPlayer` at offset `0x1118`. It reads smoothed steering at `vehicle+0x1430`, direction mode at `+0x14e5`, and tire-force multiplier at `+0x14dc`. The read is enabled only when the executable's PE timestamp is `0x6980d607` and image size is `0x2cba000`, and when the car pointer passes wheel-count, model-pointer, position, raw-input, and field-range checks. It never writes game memory. If these checks fail, the HUD explicitly says **ESTIMATE**; `~` marks a provisional grade based on input simulation.

The rater watches flights with average tire icing at or above the configured minimum, enough takeoff speed, and enough airtime. It captures the stored direction at the first all-air display sample. It captures landing steering at first visible contact, allowing up to 30 ms for the first grounded physics tick if that first sample is inside the ±10% gate. Steering changes after that window cannot rewrite the landing direction. It grades the force about 80 ms after visible contact. The first display frame can precede the grounded physics update, and the first ice landing on ANGULAR ↻ MOMENTUM still showed `1.00x` at 30 ms but `2.00x` by about 70 ms. The popup centers the grade with a brief impact animation and a short result label. It does not show force or a timestamp; the main HUD retains the force reading, and the Openplanet log retains the exact race time and measurement. The popup lasts one second by default; duration is configurable.

| Grade | Default condition | Combo |
|---|---|---|
| S | Stored direction matches landing steer; force ≥ `1.95x` | Builds; full spins add points |
| A | Same direction; force ≥ `1.75x` | Builds |
| B | Same direction; force ≥ `1.50x` | Builds |
| C | Same direction; force ≥ `1.25x` | Builds |
| D | Direction matches but force remains below `1.25x` | Breaks |
| E | No direction before takeoff, wrong direction, or no landing steer | Breaks |

The force cutoffs for S–C are settings. An estimated steering read can produce a provisional `C ~` or `E ~`; the `~` means the exact force-based grade was unavailable. The summary line shows the previous run's points and hits/misses.

**Rating scope:** The HUD measures the game fields above, but it does not directly measure longitudinal acceleration. An `S` grade means the stored direction matches landing steer and the checked tire-force multiplier meets the configured threshold. Actual speed changes still depend on the vehicle trajectory and other forces. Contact is observed once per display frame, so the exact last-wheel departure tick is not known from the HUD alone. The force sample is normally 80–90 ms after first visible contact, depending on display timing.

Controlled TICK replay validation on this build used `baseline_right`, `right_12_from_1126_through_1131`, and a post-contact steering reversal generated by the test. At the first ice landing near 6.19 s, the baseline's in-air multiplier was `1.00x`; the plugin showed `S` with `2.00x` at about 6.27 s and first drew the popup in that display frame. At the 12.58 s landing, the +12 run kept left mode before takeoff, switched right on contact, dropped to `1.00x`, and rated `E`. The reversal test ensures steering after touchdown does not turn a right-steered landing into a wrong-direction `E`. The established +13 run at that landing has stored right mode, `2.00x` force, and an instant speed trace. These exact readings and grades can be checked with `work/test_rater_in_game.py` on a local installation.
